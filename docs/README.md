# Docs

simstim runs Claude Code, Codex or any terminal agent in a session on a machine you own, over your own SSH. The session keeps running when your laptop sleeps, and you come back to the agent's real screen, byte for byte.

New here? [Install it](how-to/install.md), then follow [getting started](tutorials/getting-started.md): about five minutes from nothing to an agent on your host.
