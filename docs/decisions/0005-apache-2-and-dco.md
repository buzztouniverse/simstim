# 0005 Apache-2.0 with a DCO

## Context

The project will be open source. It may borrow from zmx (MIT) and Herdr (Apache-2.0).

## Options

1. Apache-2.0, with a Developer Certificate of Origin
2. MIT
3. A copyleft licence

## Decision

Option 1. Apache-2.0 has an explicit patent grant, is common for developer tools, and is compatible with both projects we may borrow from. A DCO sign-off is lighter than a contributor licence agreement.

## Consequences

- Good, because companies can use it without legal friction.
- Bad, because borrowed code needs attribution in `NOTICE`.
